Linda Trace — локальный анализ стиля текста

Сравнивайте стиль документов и находите тексты, которые отличаются от остальных, на своём компьютере с Windows. Тексты не покидают компьютер.

Как это работает

Сравнение документов

Загрузите от 4 до 200 документов на одном языке. В каждом должно быть не меньше 300 слов; около 1 000 слов — лучше. Linda Trace ранжирует документы по степени отличия стиля от остальных, показывает самый отличающийся документ, признаки, которые на это повлияли (значение относительно медианы остальных документов), выделяет наиболее отличающиеся фрагменты по 300 слов и строит двумерную карту стиля.

Проверка авторства

Загрузите тексты с неизвестным автором и образцы известных авторов: не менее двух образцов на каждого и не менее двух авторов. Linda Trace покажет ближайших по стилю авторов-кандидатов. Это кандидаты, а не вероятности.

Форматы: TXT, DOCX, PDF, RTF, HTML и Markdown. Для TXT доступны UTF-8, UTF-16 и выбор Windows-1251/1250/1252. Экспорт в HTML, PDF, JSON или ZIP-архив с хешами файлов. Сохранённые наборы данных (дела) остаются на компьютере. Светлая, тёмная и высококонтрастная темы; интерфейс на русском, английском и польском.

Метод объединяет около 250 стилистических признаков, векторы символьных 3–4-грамм (встроенный ресурс из 2 000 признаков на язык, обученный только на документированной литературной прозе из общественного достояния и CC0: 407 произведений) и направленную оценку cosine-delta в единый рейтинг. Статистические p-значения не приводятся: нулевая модель не прошла проверку.

Конфиденциальность

Весь анализ выполняется локально. Загруженные тексты никуда не отправляются; приложение скачивает только файлы обновлений (см. раздел «Обновления»).

Все выпуски

Установка для текущего пользователя, права администратора не нужны; на диске занимает около 160 МБ; видеокарта не требуется. Windows 10/11, 64-разрядная версия. Приложение использует WebView2, который уже есть в актуальных версиях Windows. Установщик пока не подписан, поэтому SmartScreen может показать предупреждение: нажмите «Подробнее», затем «Выполнить в любом случае» и сверьте SHA-256 выше. Данные хранятся в %LOCALAPPDATA%\ForensicAuthorship; при удалении приложение спросит, нужно ли их удалить.

Обновления

Кнопка «Обновления» в приложении проверяет подписанный список обновлений (подпись Ed25519), опубликованный на Hugging Face, и сообщает о новых пакетах моделей и версиях приложения. Пакеты моделей устанавливаются за секунды без переустановки: проверяется SHA-256, изменения применяются атомарно, а при сбое восстанавливается прежний пакет. Обновления приложения скачиваются из GitHub Releases, проверяются по подписи и SHA-256, устанавливаются без лишних шагов, затем приложение перезапускается. Автоматическую проверку при запуске можно отключить в окне обновлений. Скачиваются только список и файлы обновлений; тексты и документы не отправляются.

Ограничения

Результаты показывают относительные расстояния между стилями внутри вашего корпуса. Они не доказывают авторство, личность автора, подлинность или утечки и не заменяют экспертную проверку. Короткие тексты (менее 300 слов), списки, формы и слайды ненадёжны. Символьные n-граммы могут отражать тему или источник, а не только автора. Надёжность определения неизвестного автора не подтверждена.

Независимая проверка на отложенной выборке из 92 исторических литературных произведений (авторы умерли в 1852–1925 годах): точность top-1 у поставляемого объединённого рейтинга — 9/17 для английского, 9/19 для польского и 14/24 для русского. Только оценка n-грамм дала соответственно 12/17, 12/19 и 14/24. На современной институциональной прозе (решения Верховного суда США за 2024–2025 годы, 5 судей × 4 решения) все методы показали top-1 4/10. Для современной и корпоративной прозы никаких заявлений о качестве нет. Выборки малы; проверьте систему на своих данных, прежде чем полагаться на результат.
