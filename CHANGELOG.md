# Changelog

## 1.0.0 - 2026-10-20

First public release.

- Compare-documents mode and known-authors mode, EN / RU / PL.
- Local analysis; exports HTML, PDF, JSON and ZIP with file hashes; saved datasets.
- Updates button: Ed25519-signed update list on Hugging Face, model packs without reinstalling, application updates from GitHub Releases.
- Import fixes: RTF files with unusual code pages no longer fail, text boxes in DOCX are no longer counted twice, deeply nested DOCX paragraphs no longer slow the import.
- Model pack 1.0.0: character 3-4-gram vectors, 2,000 features per language, trained on documented public-domain and CC0 literary prose (407 works).
